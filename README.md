# 표류 뗏목 마을 3D

대홍수 이후 바다 위에 남은 뗏목에서 생존자들을 먹이고, 선원을 모아 정착지를 키우고, 쳐들어오는 해골 해적을 막아내는 3D 생존 경영 게임입니다.

## 바로 하기

- 게임 주소: https://first-village-game.pages.dev/
- QR코드: `assets/qr-3d.png` (게임 화면으로 바로 연결)

## 파일

| 파일 | 내용 |
|---|---|
| `raft-village-3d.html` | 게임 파일 (three.js). 조립 스크립트가 만든 결과물 |
| `models/*.json` | 캐릭터 모형과 동작 (glTF). 게임 파일과 같은 폴더 구조로 두어야 함 |
| `src/3d/base.html` | 게임 규칙과 화면 UI의 바탕 파일 |
| `src/3d/w3d_*.js` | 3D 모듈: 장면, 바다·뗏목·해적선, 캐릭터, 효과, 강화 카드·해적 종류·보스 |
| `src/3d/assemble3d.py` | 바탕 파일과 3D 모듈을 합쳐 게임 파일을 만드는 스크립트 |
| `src/tools/` | Blender 변환 스크립트 (팩 .blend → glTF, Mixamo 걷기 동작 옮기기) |
| `assets/qr-3d.png` | 온라인 플레이 링크 QR코드 |

## 게임 파일 다시 만들기

`src/3d`의 파일을 고친 뒤 저장소 맨 위에서 실행합니다.

```bash
python3 src/3d/assemble3d.py
```

`base.html`의 게임 규칙 위에 3D 모듈을 얹고, 3D 전용 규칙(60초 습격, 해적 레벨업, 강화 카드 등)을 덧입혀 `raft-village-3d.html`을 새로 만듭니다.

## PC에서 파일로 실행

캐릭터 파일(`models`)을 불러와야 해서 간단한 웹 서버로 여는 것이 좋습니다. 파일을 그냥 열면 도형 캐릭터로 대신 실행됩니다.

```bash
python3 -m http.server
```

그다음 브라우저에서 `http://localhost:8000/raft-village-3d.html`을 엽니다. 글꼴(Google Fonts)과 three.js는 인터넷에서 불러옵니다.

## 전략 업데이트

- 첫 뗏목 확장 후 🧭 버튼에서 다음 습격을 예측하고 준비합니다. 돌격·강습·대규모·중장갑 선단이 순환하며 상륙 간격, 검병 종류, 함선 수와 체력이 달라집니다. 3D는 예고된 특수 해적의 등장 확률도 높아집니다.
- 한 습격당 준비 선택은 한 번입니다. 기본 태세로 기다리는 것도 가능합니다.
  - **무역 강행:** 무료. 판매가 +40%, 선원이 받는 피해 +25%.
  - **방어 태세:** $20 + 완료된 습격 수 × $5. 선원 피해 -30%, 판매가 -20%, 즉시 모든 일꾼 체력 20 회복.
  - **정찰 파견:** $15 + 완료된 습격 수 × $5. 아군이 받는 피해 -15%, 판매가는 유지합니다. 습격 간격은 바뀌지 않습니다.
- 무역·방어 효과는 다음 습격 종료까지 유지됩니다. 함락되지 않고 5회 방어하면 항로 확보 보상 $200을 한 번 받고 무한 항해를 계속합니다.
- 3D 강화 카드에 밀수 항로(판매가 +35%, 습격 간격 유지), 과충전 포탄(포탑 화력 증가/아군 피해 증가), 요새 경제(아군 피해 감소/판매가 감소)가 추가됩니다.
- 기존 브라우저 저장 데이터를 유지합니다. 진행 중인 습격과 아직 고르지 않은 3D 카드도 새로고침 후 복구합니다.

## 전투 난이도 조정

- 일반·특수 상륙 해적의 기본 공격력 계수는 이전에 낮춘 값을 유지하며, 전체 체력·공격력·병력 규모는 침공 횟수와 분리한 **해적 레벨**로 계산합니다. 상어 대장의 체력과 공격력은 같은 레벨 일반 해적의 정확히 **5배**입니다.
- 해적선의 접근·퇴각 속도는 2배입니다. 해안에 도착하면 검병을 상륙시킵니다. 상륙 인원은 이전의 **3배**로, 일반선은 6명, 대형선은 12명, 보스선은 24명을 보내며 병력을 내린 배는 철수합니다. 갑판에 동시에 있을 수 있는 해적은 최대 48명입니다.
- 일꾼 선원의 운반·수금·전투 이동속도는 절반입니다. 신발 보너스는 유지하며, 주인공과 별도 해군 유닛의 이동속도는 바꾸지 않습니다.
- 상륙 해적은 시설·돈을 약탈하지 않고, 갑판 전체에서 일꾼·해군을 추격해 검으로 싸웁니다. 일꾼과 해군도 가까이 접근해 칼로 응전하며 검 궤적·피해·쓰러짐 동작을 표시합니다.
- 선원·해군이 전사해도 선장이 살아 있으면 계속 싸웁니다. 모두 쓰러지면 해적이 철수하며 승리 보상은 지급되지 않습니다. 선장과 선원이 모두 없으면 다음 습격까지 충원할 시간을 줍니다.
- 저장된 구버전 습격은 남은 체력 비율을 유지해 한 번만 전환됩니다. 다시 접속해도 체력이 중복 증가하지 않습니다.

## 전사한 일꾼 충원

- 전사한 일꾼은 자동으로 다시 생기지 않습니다. 각 텐트 앞의 민트색 **네모난 충원 칸**에 주인공이 서 있으면 빈자리가 있는 동안 한 명씩 자동 모집합니다.
- 비용은 텐트 단계와 관계없이 1명당 **고정 $30**, 생산은 **게임 시간 1초**입니다. 칸에 머무르면 순서대로 정원까지 충원하며, 칸을 떠나면 추가 결제가 멈춥니다. 이미 결제한 모집은 계속 진행됩니다.
- 자금이 부족하거나 정원이 찼거나 이미 모집 중이면 추가 결제되지 않습니다. 텐트 증축 시 새로 늘어난 두 자리만 무료로 합류하며 기존 결원은 그대로 남습니다.
- 살아 있는 일꾼의 체력·위치·짐, 전사로 생긴 빈자리, 결제한 모집 시간은 저장됩니다. 새로고침으로 무료 부활하거나 모집 비용이 재청구되지 않습니다.

## 선장 전투 성장과 보스

- 선장은 상륙 해적 가까이 가면 검을 휘둘러 싸웁니다. 원거리 물총 대신 선원과 함께 갑판 전투에 참여합니다.
- 실제 타격당 전투 경험치 2, 처치 시 추가 8(보스는 28)을 얻습니다. 전투 레벨 50 미만에서 참전한 습격을 승리하면 최소 한 레벨을 더 올리는 경험치를 한 번 받습니다. 판매 경험치는 생산 숙련도에만 반영됩니다.
- 기본 공격력 4, 체력 40에서 시작하며 `(4 + 2 × (레벨−1))`, `(40 + 6 × (레벨−1))`에 아군 단계별 10% 성장 배율을 적용합니다(해적 성장 3%와 별도). 훈련과 카드 보너스는 추가로 유지합니다. 상단에 선장 레벨·경험치·공격력·체력을 표시합니다. 기존 저장의 레벨은 최초 한 번 선장 레벨의 시작값으로 이어받습니다.
- 선장이 쓰러지면 8초 뒤 무료 회복합니다. 회복 대기 중에는 이동·전투·자동 충원 결제를 멈춥니다. 전투 레벨·경험치·체력·보스 상태는 새로고침 후에도 유지됩니다.
- 보스 출현 기준은 **주인공 레벨이 아닌 해적 습격 레벨**입니다. 해적 5·10·15레벨에 도달할 때 상어 대장이 한 번씩 상륙합니다. 같은 해적 레벨이 이어지는 세 번의 습격에서 보스가 중복 등장하지 않습니다.

## 50레벨 성장과 느린 해적 레벨업

- 주인공의 전투 레벨은 최대 50이며, 영웅·선원 훈련소도 각각 50단계까지 강화합니다. 기존 10단계에서 계속 강화할 수 있습니다.
- 침공마다 해적 레벨이 1씩 오르며 **상한이 없습니다**. 해적의 체력·공격력은 레벨마다 **3%씩** 복리로 오릅니다. 선장의 전투 레벨(최대 50)은 기존 획득 레벨과 해당 성장 단계 중 높은 값을 유지하고, 선원도 같은 침공 단계로 성장합니다(아군 성장은 단계별 10%). 습격 준비 시간은 기존 60초를 유지합니다.
- 해적 Lv.5·10·15…마다 보스가 한 번씩 등장합니다. 같은 레벨의 보스는 반복하지 않습니다. 보스 체력·공격력은 같은 레벨의 일반 검병 기준 5배이며, 전술과 방어 카드의 피해 감소 효과도 동일하게 적용됩니다.
- 예전 29회차 저장은 침공 횟수를 유지하면서 해적 Lv.10 난이도로 조정합니다. 진행 중인 해적의 남은 체력 비율은 보존하며 한 번만 새 난이도로 전환합니다. 재화·시설·아군 성장·부상은 유지됩니다.
- 상점 수입·처치 보상은 기존 침공 횟수를 유지합니다. 강화 비용은 지수 증가 대신 일정 금액씩 올라 50단계까지 도달할 수 있도록 조정했습니다.

## 방어 규칙 (일꾼 6명부터 침공)

- 살아 있는 일꾼이 **6명 이상**일 때만 습격 카운트다운이 흐릅니다. 그 전에는 화면에 `일꾼 n/6명 · 6명이 모이면 해적 침공`이 표시됩니다.
- 방어 인원(일꾼·해군·주인공)이 모두 쓰러지면 해적은 물러나지 않고 가까운 시설을 칼로 부숩니다(시설 체력 120 + 업그레이드 단계마다 30). 공격받는 시설에는 체력 막대가 보입니다.
- 주인공이 회복하면 해적은 다시 주인공과 싸우고, 주인공이 끝까지 물리쳐야 습격이 끝납니다.
- 부서진 시설은 기울어지고 연기가 나며 생산·판매가 멈춥니다. 할 일이 없는 일꾼이 스스로 가서 고칩니다(시설 하나에 최대 3명, 일꾼 1명 기준 4초, 머리 위 🔧 표시). 주인공이 옆에 2초 서 있어도 수리됩니다. 근처에 해적이 있으면 수리되지 않습니다.
- 가판대에는 들고 있는 물건을 **개수 제한 없이 전부** 올릴 수 있습니다(화면에는 30개까지 쌓아 보여 줌).
- 일꾼은 일할 때 칼을 넣어 두고, 해적과 맞붙을 때만 칼을 손에 쥡니다.

## 시설 배치 정리

- 영웅·선원 훈련소는 위쪽 가운데(예전 빗물 정수기 자리)로, 빗물 정수기는 오른쪽 위(물 배급소 근처)로 자리를 바꿨습니다.
- 태양광 패널과 구조 신호탑은 없앴습니다. 예전 저장에서 지었거나 돈을 넣어 둔 경우 그 금액을 한 번 돌려받습니다. 뗏목 확장(2차)은 물 배급소를 지은 뒤 열립니다.

## 영웅·선원 강화 시설

첫 뗏목 확장과 일꾼 텐트 건설을 마치면 오른쪽 훈련 부두에 두 시설의 건설 칸이 나타납니다. 기존 저장으로 접속해도 부두가 연결됩니다.

| 시설 | 건설비 | 첫 강화 비용 | 단계마다 얻는 효과 |
|---|---:|---:|---|
| 영웅 훈련소 | $100 | $60 | 주인공 공격력 +3, 최대 체력 +10 |
| 선원 훈련소 | $120 | $50 | 모든 일꾼 공격력 +1, 최대 체력 +5 |

- 각 시설 앞 네모 칸(영웅 강화·일꾼 강화)에 주인공이 서 있으면 **건설·업그레이드 칸과 같은 방식으로** 돈이 조금씩 들어가 게이지가 차고, 다 차면 한 단계 강화됩니다. 칸에는 남은 금액이 표시되고, 칸을 떠나면 결제가 멈추며 넣어 둔 돈(게이지)은 저장되어 다음에 이어집니다. 별도의 강화 화면은 열리지 않습니다.
- 각각 최대 **50단계**입니다. 강화 비용은 현재 단계 기준 영웅 `$60 + 단계 × $25`, 선원 `$50 + 단계 × $20`으로 완만하게 증가합니다. 돈이 부족하거나 시설을 짓지 않았거나 영웅이 쓰러져 있으면 구매할 수 없습니다.
- 강화는 전투 레벨·카드와 함께 적용됩니다. 현재 일꾼과 나중에 $30로 충원한 일꾼 모두 선원 강화 효과를 받으며, 별도 해군 병사의 능력치는 유지합니다.
- 강화 시 기존에 잃은 체력은 유지하며 최대 체력 증가분만 채워 줍니다. 죽은 일꾼은 부활하지 않습니다. 시설·강화 단계·유닛 체력은 저장됩니다.

## 판매소 배정과 자동 판매

- 오른쪽 아래 **👷 일꾼 배정**에서 각 판매소의 담당 인원을 +/−로 지정합니다. 배정 합계는 살아 있는 인원이 아닌 텐트 전체 정원을 기준으로 제한합니다.
- 담당자는 지정 판매소에 상품을 공급하고 판매 대금을 수거합니다. 식당 담당자는 화로에 생선을 공급하는 작업도 맡습니다. 같은 작업자의 도착 지점을 분산하고 겹친 일꾼을 분리합니다.
- 전사해도 지정 정원은 유지됩니다. 텐트 앞에서 기존과 같이 $30·1초로 충원하면 결원을 채웁니다. 배정과 근무지는 저장됩니다. 새 판매소에는 배정 화면에서 인원을 지정하세요.
- 손님은 생성하지 않습니다. 각 판매소는 게임 시간 2초마다 재고 한 개를 자동 판매하며 판매 대금은 기존 수금 위치에 쌓입니다. 영웅과 담당 일꾼의 수금 방식은 유지합니다. 판매 주기의 남은 시간도 저장합니다.
- 배정을 바꾸는 도중 들고 있던 다른 상품은 원래 생산소로 반환해 잃지 않습니다. 운반물은 영웅·선원의 머리 위 중앙에 쌓으며 크기와 적재 간격은 기존의 3배입니다.

## 습격 간격

- 첫 확장 후 첫 습격과 각 전투 종료 뒤 다음 습격까지 **게임 시간 60초**를 준비합니다. 진행 중인 전투에 다음 습격을 겹쳐 생성하지 않습니다.
- 밀수 카드와 정찰로 간격을 줄이거나 늘리지 않습니다. 정찰은 받는 피해를 15% 낮춥니다.
- 이전 버전의 대기 중인 습격은 처음 접속할 때 한 번만 60초로 전환합니다. 이후 새로고침에서는 남은 시간이 유지됩니다.
- 이미 결제한 예전 5초 모집은 재결제 없이 남은 시간을 최대 1초로 줄여 이어받습니다.

## 공개 배포와 QR코드

게임은 **Cloudflare Pages**로 배포합니다. `main`에 올리면 Cloudflare가 자동으로 다시 배포합니다.

| Cloudflare Pages 설정 | 값 |
|---|---|
| Project name | `first-village-game` |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `sh src/tools/build_site.sh` |
| Build output directory | `_site` |

`build_site.sh`는 게임 실행에 필요한 파일(`index.html`, `raft-village-3d.html`, `models`, `assets`)만 `_site`에 모읍니다. 소스·테스트·문서는 공개되지 않습니다.

주소가 바뀌면 QR을 다시 생성합니다 (Python 패키지 `qrcode==8.2` 필요).

```bash
python3 src/tools/generate_qr.py --base-url https://first-village-game.pages.dev
```

## 브라우저 회귀 검증

이번 변경의 검증은 `tests/update_game.py`, `tests/training_game.py`, `tests/smoke_game.py`, `tests/visual_game.py`를 사용합니다. 기존 손님 동선·3회 침공 성장 규칙을 전제하는 다른 검사는 이전 버전용입니다.

Python Playwright, Pillow(렌더 캡처 확인), Chromium(`/usr/bin/chromium`), curl이 필요합니다. 저장소에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행한 뒤 별도 터미널에서 실행합니다.

```bash
python3 tests/smoke_game.py
python3 tests/visual_game.py --screenshots /tmp/my-game-screenshots
python3 tests/combat_game.py
python3 tests/characters_game.py --screenshots /tmp/my-game-characters
python3 tests/melee_recruit_game.py --screenshots /tmp/my-game-melee
python3 tests/hero_boss_game.py
python3 tests/training_game.py
python3 tests/update_game.py
```

준비 비용·효과, 중복 선택 방지, 저장·습격 복구, 방어 보상 중복 방지, 3D 카드 선택 복구와 JavaScript 실행 오류를 확인합니다. 테스트는 별도 브라우저 컨텍스트에서 실행되며 실제 사용자의 저장 데이터를 건드리지 않습니다. 화면 검증은 터치와 DPR 2를 설정한 실제 모바일 브라우저 문맥에서 320·390px 세로 화면과 가로 화면의 viewport 배율·HUD 겹침·터치 스크롤·드래그 방향을 확인합니다. 데스크톱 키보드 조작, 시설 표시, 습격 안내와 전투 카메라도 검사합니다. 전투 검증은 이전 버전과 체력·공격력·속도를 비교하고 상륙 전투와 저장 이관을 확인합니다. 캐릭터 검증은 원본 모델과 로딩 실패 시 임시 모델을 실제로 렌더링합니다. 외부 글꼴은 테스트에서 제외하며 three.js는 TLS 검증을 유지한 curl을 통해 불러옵니다.

## 주요 기능

- **생산과 판매:** 낚시터, 숯불 화로, 빗물 정수기, 텃밭과 판매소 4곳. 손님 없이 각 판매소에서 2초마다 상품 한 개 자동 판매
- **선원:** 텐트마다 선원이 합류해 일을 골고루 나눠 맡고 쌓인 돈도 주움. 습격 때는 해적과 싸우고, 전사하면 텐트 앞 칸에서 $30씩 자동 충원
- **강화 시설:** 첫 확장 뒤 영웅·선원 훈련소를 건설해 각각 50단계까지 능력치를 유료 강화
- **성장:** 선장 전투 레벨(최대 50, 침공 단계 보장·기존 레벨 유지), 생산 숙련도, 건물 ★ 업그레이드, 뗏목 확장, 물고기 떼, 업적형 미니 퀘스트
- **캐릭터:** 주인공은 오리지널 "바다 수호 기사"입니다. Henry 모형을 바탕으로 남색 옷·갈색 머리로 색을 바꾸고, 금빛 조개 볏을 단 둥근 은빛 투구·가슴판·어깨 보호대·큰 은빛 주먹·장화·산호색 목도리를 뼈대에 붙여 원본 걷기·달리기·전투·사망 동작을 그대로 따라갑니다. 일꾼(선원)은 오리지널 "뼈다귀 곰 선원"입니다. 같은 Henry 동작 위에 몸보다 큰 둥근 곰 해골 머리(반짝이는 눈·분홍 볼터치·분홍 귀 안쪽·동그란 코), 머리와 같은 하얀 몸, 연한 라벤더색 뼈 무늬, 동그란 꼬리, 청록 선원 스카프를 입혔습니다. 손님은 Henry(붉은 두건)입니다.
- **상륙 해적:** 원본 Mako·Sharky 상어 인간과, 검은 해골 돛·빨간 깃발·대포를 단 해적선입니다. 참고 그림의 여성·원본 해골 캐릭터는 현재 저장소 모델에 포함되어 있지 않습니다.
- **습격:** 전투 종료 후 60초 준비 뒤 습격. 상륙 해적은 이전의 3배. 침공마다 해적 레벨이 1 오르고(상한 없음), 레벨마다 체력·공격력이 3%씩 성장
- **해적 종류:** 일반·강습·돌격·정예 검병. 기존 유형별 체력·이동 특성은 유지하고 모두 갑판 백병전을 수행
- **보스:** 해적 Lv.5·10·15…50에 도달하면 거대 해적선과 상어 대장이 한 번씩 등장. 보스가 직접 상륙해 선장·일꾼·해군과 칼로 싸우며, 보스선이 먼저 침몰해도 전투는 이어집니다
- **강화 카드:** 습격을 막을 때마다 15종 중 3장이 나오고 1장을 골라 판마다 다르게 성장
- **방어:** 망루 포탑과 포대. 해적은 약탈 대신 일꾼·해군과 칼로 싸움. 전사한 일꾼은 텐트에서 유료 충원
- **화면:** 밝은 모바일 타이쿤 스타일. 대각선 직교 카메라, 큼직한 원본 해적 캐릭터와 흰색 건설 가격판, 밝은 천막·가판대, 크림색 테두리 UI를 사용합니다. 선장 모자와 발밑 표시로 주인공을 구분합니다.
- **배경:** 열대 해안 분위기. 뗏목과 섬 가까이는 맑은 청록, 멀수록 짙은 파랑으로 바뀌는 바다와 가장자리 물거품, 뗏목 둘레의 모래 해변·야자수, 초록 덤불을 얹은 바위 절벽과 바위 기둥, 기둥 위 오두막, 정박한 범선과 작은 배, 물거품 바위 (`src/3d/w3d_scenery.js`). 손님 부두와 낚시터 물길은 비워 두었습니다.
- **저장:** 진행 상황은 브라우저에 자동 저장
