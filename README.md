# 표류 뗏목 마을 3D

대홍수 이후 바다 위에 남은 뗏목에서 생존자들을 먹이고, 선원을 모아 정착지를 키우고, 쳐들어오는 해골 해적을 막아내는 3D 생존 경영 게임입니다.

## 바로 하기

- 수정본 공개 실행 페이지 (배포 후): https://minseok3773.github.io/my-game/
- QR코드는 공개 배포 후 수정본을 실행합니다.
- QR코드: `assets/qr-3d.png`

## 파일

| 파일 | 내용 |
|---|---|
| `raft-village-3d.html` | 게임 파일 (three.js). 조립 스크립트가 만든 결과물 |
| `models/*.json` | 캐릭터 모형과 동작 (glTF). 게임 파일과 같은 폴더 구조로 두어야 함 |
| `src/3d/base.html` | 게임 규칙과 화면 UI의 바탕 파일 |
| `src/3d/w3d_*.js` | 3D 모듈: 장면, 바다·뗏목·해적선, 캐릭터, 효과, 강화 카드·해적 종류·보스 |
| `src/3d/assemble3d.py` | 바탕 파일과 3D 모듈을 합쳐 게임 파일을 만드는 스크립트 |
| `src/tools/` | Blender 변환 스크립트 (팩 .blend → glTF, Mixamo 걷기 동작 옮기기) |
| `assets/qr-3d.png` | 온라인 플레이 링크 QR코드 |

## 게임 파일 다시 만들기

`src/3d`의 파일을 고친 뒤 저장소 맨 위에서 실행합니다.

```bash
python3 src/3d/assemble3d.py
```

`base.html`의 게임 규칙 위에 3D 모듈을 얹고, 3D 전용 규칙(30초 습격, 해적 레벨업, 강화 카드 등)을 덧입혀 `raft-village-3d.html`을 새로 만듭니다.

## PC에서 파일로 실행

캐릭터 파일(`models`)을 불러와야 해서 간단한 웹 서버로 여는 것이 좋습니다. 파일을 그냥 열면 도형 캐릭터로 대신 실행됩니다.

```bash
python3 -m http.server
```

그다음 브라우저에서 `http://localhost:8000/raft-village-3d.html`을 엽니다. 글꼴(Google Fonts)과 three.js는 인터넷에서 불러옵니다.

## 전략 업데이트

- 첫 뗏목 확장 후 🧭 버튼에서 다음 습격을 예측하고 준비합니다. 돌격·폭파·약탈·중장갑 선단이 순환하며 상륙 간격, 포격 빈도, 함선 수와 체력이 달라집니다. 3D는 예고된 특수 해적의 등장 확률도 높아집니다.
- 한 습격당 준비 선택은 한 번입니다. 기본 태세로 기다리는 것도 가능합니다.
  - **무역 강행:** 무료. 판매가 +40%, 마을이 받는 피해 +25%.
  - **방어 태세:** $20 + 완료된 습격 수 × $5. 마을 피해 -30%, 판매가 -20%, 즉시 체력 20 회복.
  - **정찰 파견:** $15 + 완료된 습격 수 × $5. 준비 시간 20초 추가.
- 무역·방어 효과는 다음 습격 종료까지 유지됩니다. 함락되지 않고 5회 방어하면 항로 확보 보상 $200을 한 번 받고 무한 항해를 계속합니다.
- 3D 강화 카드에 밀수 항로(판매가 증가/습격 간격 감소), 과충전 포탄(포탑 화력 증가/마을 피해 증가), 요새 경제(마을 피해 감소/판매가 감소)가 추가됩니다.
- 기존 브라우저 저장 데이터를 유지합니다. 진행 중인 습격과 아직 고르지 않은 3D 카드도 새로고침 후 복구합니다.

## 전투 난이도 조정

- 일반·특수 상륙 해적, 일반·대형 해적선과 보스의 체력 및 공격력을 이전 버전의 2배로 올렸습니다. 습격 레벨에 따른 성장 배율은 그대로 적용합니다.
- 해적선의 접근·퇴각 속도는 2배입니다. 해안에 도착하면 첫 상륙을 바로 시작하고, 이후 상륙 간격과 인원 제한은 유지합니다.
- 일꾼 선원의 운반·수금·전투 이동속도는 절반입니다. 신발·태양광 보너스는 유지하며, 주인공과 별도 해군 유닛의 이동속도는 바꾸지 않습니다.
- 저장된 구버전 습격은 남은 체력 비율을 유지해 한 번만 전환됩니다. 다시 접속해도 체력이 중복 증가하지 않습니다.

## 공개 배포와 QR코드

1. 변경 파일을 GitHub 저장소에 올립니다.
2. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다.
3. **Actions → Publish game to GitHub Pages → Run workflow**를 실행합니다. 이후 `main`에 푸시하면 자동 배포됩니다.
4. 배포 성공 후 공개 실행 페이지와 게임을 휴대폰에서 확인합니다. 그다음 QR코드를 공유하세요. 클라우드 환경 게시와 GitHub Pages 게임 배포는 별개입니다.

주소가 바뀌면 QR을 다시 생성합니다 (Python 패키지 `qrcode==8.2` 필요).

```bash
python3 src/tools/generate_qr.py --base-url https://minseok3773.github.io/my-game
```

## 브라우저 회귀 검증

Python Playwright, Chromium(`/usr/bin/chromium`), curl이 필요합니다. 저장소에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행한 뒤 별도 터미널에서 실행합니다.

```bash
python3 tests/smoke_game.py
python3 tests/visual_game.py --screenshots /tmp/my-game-screenshots
python3 tests/combat_game.py
python3 tests/characters_game.py --screenshots /tmp/my-game-characters
```

준비 비용·효과, 중복 선택 방지, 저장·습격 복구, 방어 보상 중복 방지, 3D 카드 선택 복구와 JavaScript 실행 오류를 확인합니다. 테스트는 별도 브라우저 컨텍스트에서 실행되며 실제 사용자의 저장 데이터를 건드리지 않습니다. 화면 검증은 터치와 DPR 2를 설정한 실제 모바일 브라우저 문맥에서 320·390px 세로 화면과 가로 화면의 viewport 배율·HUD 겹침·터치 스크롤·드래그 방향을 확인합니다. 데스크톱 키보드 조작, 시설 표시, 습격 안내와 전투 카메라도 검사합니다. 전투 검증은 이전 버전과 체력·공격력·속도를 비교하고 상륙 전투와 저장 이관을 확인합니다. 캐릭터 검증은 원본 모델과 로딩 실패 시 임시 모델을 실제로 렌더링합니다. 외부 글꼴은 테스트에서 제외하며 three.js는 TLS 검증을 유지한 curl을 통해 불러옵니다.

## 조작

- 화면을 끌어서 이동 (PC: WASD / 방향키)
- 시설 옆에 서 있으면 물건을 자동으로 싣고 내림
- 왼쪽 아래 🎒 또는 Q 키로 가방 비우기
- 점선 칸 위에 서 있으면 돈이 들어가고, 다 채우면 건설·업그레이드

## 주요 기능

- **생산과 판매:** 낚시터, 숯불 화로, 빗물 정수기, 텃밭과 가게 4곳. 손님은 기다릴수록 표정이 바뀌고 15초가 지나면 떠남
- **선원:** 텐트마다 선원이 합류해 일을 골고루 나눠 맡고 쌓인 돈도 주움. 습격 때는 해적과 싸우고, 쓰러지면 45초 뒤 텐트에서 새 선원이 옴
- **성장:** 레벨, 건물 ★ 업그레이드, 뗏목 확장, 물고기 떼, 업적형 미니 퀘스트
- **캐릭터:** 원본 Pirate Kit의 Captain Barbarossa(선장 모자·수염·앵무새)가 주인공, Henry(붉은 두건)가 선원·손님입니다. 토끼 모자와 임의 재색상을 제거했으며 원본 걷기·달리기·전투·사망 동작을 사용합니다.
- **상륙 해적:** 원본 Mako·Sharky 상어 인간과, 검은 해골 돛·빨간 깃발·대포를 단 해적선입니다. 참고 그림의 여성·원본 해골 캐릭터는 현재 저장소 모델에 포함되어 있지 않습니다.
- **습격:** 30초마다 습격. 습격할 때마다 해적이 레벨업하여 체력·공격력이 10%씩 복리로 상승
- **해적 종류:** 일반, 💣 폭탄(시설에 닿으면 폭발), 💰 도둑(돈을 훔쳐 배로 도망, 잡으면 되찾음), 🎯 저격(멀리서 선원을 쏨)
- **보스:** 5번째 습격마다 해골 선장의 거대 해적선. 일제 사격과 졸개 소환
- **강화 카드:** 습격을 막을 때마다 15종 중 3장이 나오고 1장을 골라 판마다 다르게 성장
- **방어:** 망루 포탑과 포대. 마을이 함락되면 자금 약탈·시설 파손
- **화면:** 밝은 모바일 타이쿤 스타일. 대각선 직교 카메라, 큼직한 원본 해적 캐릭터와 흰색 건설 가격판, 밝은 천막·가판대, 크림색 테두리 UI를 사용합니다. 손님은 짧은 두 줄 대기열로 배치하고 앞쪽 손님 위주로 감정 말풍선을 표시합니다. 선장 모자와 발밑 표시로 주인공을 구분합니다.
- **저장:** 진행 상황은 브라우저에 자동 저장
