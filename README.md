# 표류 뗏목 마을 3D

대홍수 이후 바다 위에 남은 뗏목에서 생존자들을 먹이고, 선원을 모아 정착지를 키우고, 쳐들어오는 해골 해적을 막아내는 3D 생존 경영 게임입니다.

## 바로 하기

- 게임 주소: https://first-village-game.pages.dev/
- QR코드: `assets/qr-3d.png` (게임 화면으로 바로 연결)

## 미션 길 안내

- **바닥 점선:** 주인공 발밑에서 현재 목표 칸까지 흐르는 점선이 그려집니다. 가까워질수록 짧아지고, 도착하면 사라집니다. 색은 건설(노랑) · 작업(청록) · 습격(빨강).
- **화면 밖 화살표:** 목표가 화면 밖이면 가장자리에 방향 화살표와 아이콘, 남은 거리(m)가 표시됩니다.
- **목표 미리 보기:** 위쪽 안내문(👀 표시)을 누르면 카메라가 목표 칸을 잠깐 비춘 뒤 주인공에게 돌아옵니다.
- 코드: `src/3d/w3d_guide.js`

## 홈 화면 앱으로 설치 (PWA)

- **안드로이드(크롬):** 게임 주소를 연 뒤 오른쪽 위 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**.
- **아이폰(사파리):** 아래쪽 공유 버튼 → **홈 화면에 추가**.
- 홈 화면의 뗏목 아이콘을 누르면 주소창 없이 전체 화면 세로 모드로 바로 게임이 열립니다.
- 처음 한 번 인터넷으로 열면 게임 파일이 휴대폰에 저장되어, 이후에는 **인터넷이 없어도** 실행됩니다. 인터넷이 될 때는 항상 최신 게임을 받아 옵니다.
- 관련 파일: `manifest.webmanifest`(앱 이름·아이콘), `sw.js`(오프라인 저장), `assets/icon-*.png`(`src/tools/make_icons.py`로 생성). 오프라인 저장은 실제 https 사이트에서만 켜지고 자동 테스트 브라우저에서는 꺼집니다(`?sw=1`로 강제 가능).

## 파일

| 파일 | 내용 |
|---|---|
| `raft-village-3d.html` | 게임 파일 (three.js). 조립 스크립트가 만든 결과물 |
| `models/*.json` | 캐릭터 모형과 동작 (glTF). 게임 파일과 같은 폴더 구조로 두어야 함 |
| `src/3d/base.html` | 게임 규칙과 화면 UI의 바탕 파일 |
| `src/3d/w3d_*.js` | 3D 모듈: 장면, 바다·뗏목·해적선, 캐릭터, 효과, 강화 카드·해적 종류·보스 |
| `src/3d/assemble3d.py` | 바탕 파일과 3D 모듈을 합쳐 게임 파일을 만드는 스크립트 |
| `src/tools/` | Blender 변환 스크립트 (팩 .blend → glTF, Mixamo 걷기 동작 옮기기) |
| `assets/qr-3d.png` | 온라인 플레이 링크 QR코드 |

## 게임 파일 다시 만들기

`src/3d`의 파일을 고친 뒤 저장소 맨 위에서 실행합니다.

```bash
python3 src/3d/assemble3d.py
```

`base.html`의 게임 규칙 위에 3D 모듈을 얹고, 3D 전용 규칙(60초 습격, 해적 레벨업, 강화 카드 등)을 덧입혀 `raft-village-3d.html`을 새로 만듭니다.

## PC에서 파일로 실행

캐릭터 파일(`models`)을 불러와야 해서 간단한 웹 서버로 여는 것이 좋습니다. 파일을 그냥 열면 도형 캐릭터로 대신 실행됩니다.

```bash
python3 -m http.server
```

그다음 브라우저에서 `http://localhost:8000/raft-village-3d.html`을 엽니다. three.js r128과 필수 부속 스크립트는 `vendor/three-r128`에 포함되어 있어 외부 CDN 연결 없이 실행됩니다. Google Fonts는 선택 사항이며 연결되지 않으면 기기 글꼴을 사용합니다. 필수 파일이나 WebGL을 불러오지 못하면 원인 안내와 재시도 버튼을 표시합니다.

## 모바일 화면과 캐릭터 크기

- 게임 화면은 CSS 표시 영역과 3D·2D 캔버스의 실제 해상도를 함께 갱신합니다. 화면 회전, 모바일 주소창 높이 변화, 화면 복귀와 픽셀 비율 변경에도 크기를 맞춥니다.
- 공격력과 체력은 긴 소수점을 정리해 표시하고, 큰 자금과 능력치는 축약합니다. 상태 표시로 실제 전투·경제 수치가 바뀌지는 않습니다.
- 선장·일꾼·해군·해적·보스·돌고래 손님과 해적선 장식 선원은 이전 모형 크기의 **2/3**입니다. 장비·운반물도 함께 축소하며 건물·배와 게임 이동 좌표는 유지합니다.

## 저장과 오류 복구

- 자동 저장에 실패하면 상단 안내와 메뉴에 경고를 표시합니다. 메뉴에서 저장을 다시 시도하거나 현재 진행을 JSON 파일로 내려받을 수 있습니다.
- 기본 저장이 손상된 경우 이전 정상 저장 백업이 있으면 복구합니다. 기존 저장을 읽지 못한 상태에서는 자동 저장으로 원본을 덮어쓰지 않습니다. 사용자가 두 번 확인한 새 게임 초기화에서만 이 보호를 해제합니다.
- 선장은 최대 50레벨, 해적은 상한 없이 성장합니다. 구버전에서 50을 넘긴 선장은 레벨을 50으로 정리하되 이미 얻은 공격력·최대 체력은 별도 보너스로 보존합니다. 새로고침을 반복해도 보너스가 중복 적용되지 않습니다.
- 일꾼은 생산시설이 파손돼도 이미 든 물건을 배달합니다. 판매소까지 파손됐으면 물건을 보존하며 수리한 뒤 배달합니다.
- 일반 안내는 상단에 표시되며 저장 오류·선장 회복·전투 안내를 가리지 않습니다. 하단 안내창은 표시하지 않습니다.

## 전략 업데이트

- 첫 뗏목 확장 후 🧭 버튼에서 다음 습격을 예측하고 준비합니다. 돌격·강습·대규모·중장갑 선단이 순환하며 상륙 간격, 검병 종류, 함선 수와 체력이 달라집니다. 3D는 예고된 특수 해적의 등장 확률도 높아집니다.
- 한 습격당 준비 선택은 한 번입니다. 기본 태세로 기다리는 것도 가능합니다.
  - **무역 강행:** 무료. 판매가 +40%, 선원이 받는 피해 +25%.
  - **방어 태세:** $20 + 완료된 습격 수 × $5. 선원 피해 -30%, 판매가 -20%, 즉시 모든 일꾼 체력 20 회복.
  - **정찰 파견:** $15 + 완료된 습격 수 × $5. 아군이 받는 피해 -15%, 판매가는 유지합니다. 습격 간격은 바뀌지 않습니다.
- 무역·방어 효과는 다음 습격 종료까지 유지됩니다. 함락되지 않고 5회 방어하면 항로 확보 보상 $200을 한 번 받고 무한 항해를 계속합니다.
- 3D 강화 카드에 밀수 항로(판매가 +35%, 습격 간격 유지), 과충전 포탄(포탑 화력 증가/아군 피해 증가), 요새 경제(아군 피해 감소/판매가 감소)가 추가됩니다.
- 기존 브라우저 저장 데이터를 유지합니다. 진행 중인 습격과 아직 고르지 않은 3D 카드도 새로고침 후 복구합니다.

## 전투 난이도 조정

- 일반·특수 상륙 해적의 기본 공격력 계수는 이전에 낮춘 값을 유지하며, 전체 체력·공격력·병력 규모는 침공 횟수와 분리한 **해적 레벨**로 계산합니다. 상어 대장의 체력과 공격력은 같은 레벨 일반 해적의 정확히 **5배**입니다.
- 해적선의 접근·퇴각 속도는 2배입니다. 해안에 도착하면 검병을 상륙시킵니다. 상륙 인원은 이전의 **3배**로, 일반선은 6명, 대형선은 12명, 보스선은 24명을 보내며 병력을 내린 배는 철수합니다. 갑판에 동시에 있을 수 있는 해적은 최대 48명입니다.
- 일꾼 선원의 운반·수금·전투 이동속도는 절반입니다. 신발 보너스는 유지하며, 주인공과 별도 해군 유닛의 이동속도는 바꾸지 않습니다.
- 상륙 해적은 시설·돈을 약탈하지 않고, 갑판 전체에서 일꾼·해군을 추격해 검으로 싸웁니다. 일꾼과 해군도 가까이 접근해 칼로 응전하며 검 궤적·피해·쓰러짐 동작을 표시합니다.
- 선원·해군이 전사해도 선장이 살아 있으면 계속 싸웁니다. 모두 쓰러지면 해적이 철수하며 승리 보상은 지급되지 않습니다. 선장과 선원이 모두 없으면 다음 습격까지 충원할 시간을 줍니다.
- 저장된 구버전 습격은 남은 체력 비율을 유지해 한 번만 전환됩니다. 다시 접속해도 체력이 중복 증가하지 않습니다.

## 전사한 일꾼 충원

- 전사한 일꾼은 자동으로 다시 생기지 않습니다. 각 텐트 앞의 민트색 **네모난 충원 칸**에 주인공이 서 있으면 빈자리가 있는 동안 한 명씩 자동 모집합니다.
- 비용은 텐트 단계와 관계없이 1명당 **고정 $30**, 생산은 **게임 시간 1초**입니다. 칸에 머무르면 순서대로 정원까지 충원하며, 칸을 떠나면 추가 결제가 멈춥니다. 이미 결제한 모집은 계속 진행됩니다.
- 자금이 부족하거나 정원이 찼거나 이미 모집 중이면 추가 결제되지 않습니다. 텐트 증축 시 새로 늘어난 두 자리만 무료로 합류하며 기존 결원은 그대로 남습니다.
- 살아 있는 일꾼의 체력·위치·짐, 전사로 생긴 빈자리, 결제한 모집 시간은 저장됩니다. 새로고침으로 무료 부활하거나 모집 비용이 재청구되지 않습니다.

## 선장 전투 성장과 보스

- 선장은 상륙 해적 가까이 가면 검을 휘둘러 싸웁니다. 원거리 물총 대신 선원과 함께 갑판 전투에 참여합니다.
- 실제 타격당 전투 경험치 2, 처치 시 추가 8(보스는 28)을 얻습니다. 전투 레벨 50 미만에서 참전한 습격을 승리하면 최소 한 레벨을 더 올리는 경험치를 한 번 받습니다. 판매 경험치는 생산 숙련도에만 반영됩니다.
- 기본 공격력 4, 체력 40에서 시작하며 `(4 + 2 × (레벨−1))`, `(40 + 6 × (레벨−1))`에 아군 단계별 6% 성장 배율을 적용합니다(해적 성장 3%와 별도). 훈련과 카드 보너스는 추가로 유지합니다. 상단에 선장 레벨·경험치·공격력·체력을 표시합니다. 기존 저장의 레벨은 최초 한 번 선장 레벨의 시작값으로 이어받습니다.
- 선장이 쓰러지면 8초 뒤 무료 회복합니다. 회복 대기 중에는 이동·전투·자동 충원 결제를 멈춥니다. 전투 레벨·경험치·체력·보스 상태는 새로고침 후에도 유지됩니다.
- 보스 출현 기준은 **주인공 레벨이 아닌 해적 습격 레벨**입니다. 해적 5·10·15레벨에 도달할 때 상어 대장이 한 번씩 상륙합니다. 같은 해적 레벨이 이어지는 세 번의 습격에서 보스가 중복 등장하지 않습니다.

## 50레벨 성장과 느린 해적 레벨업

- 주인공의 전투 레벨은 최대 50이며, 영웅·선원 훈련소도 각각 50단계까지 강화합니다. 기존 10단계에서 계속 강화할 수 있습니다.
- 침공마다 해적 레벨이 1씩 오르며 **상한이 없습니다**. 해적의 체력·공격력은 레벨마다 **3%씩** 복리로 오릅니다. 선장의 전투 레벨(최대 50)은 기존 획득 레벨과 해당 성장 단계 중 높은 값을 유지하고, 선원도 같은 침공 단계로 성장합니다(아군 성장은 단계별 6%). 습격 준비 시간은 기존 60초를 유지합니다.
- 해적 Lv.5·10·15…마다 보스가 한 번씩 등장합니다. 같은 레벨의 보스는 반복하지 않습니다. 보스 체력·공격력은 같은 레벨의 일반 검병 기준 5배이며, 전술과 방어 카드의 피해 감소 효과도 동일하게 적용됩니다.
- 예전 29회차 저장은 침공 횟수를 유지하면서 해적 Lv.10 난이도로 조정합니다. 진행 중인 해적의 남은 체력 비율은 보존하며 한 번만 새 난이도로 전환합니다. 재화·시설·아군 성장·부상은 유지됩니다.
- 상점 수입·처치 보상은 기존 침공 횟수를 유지합니다. 강화 비용은 지수 증가 대신 일정 금액씩 올라 50단계까지 도달할 수 있도록 조정했습니다.

## 방어 규칙 (일꾼 6명부터 침공)

- 살아 있는 일꾼이 **6명 이상**일 때만 습격 카운트다운이 흐릅니다. 그 전에는 화면에 `일꾼 n/6명 · 6명이 모이면 해적 침공`이 표시됩니다.
- 방어 인원(일꾼·해군·주인공)이 모두 쓰러지면 해적은 물러나지 않고 가까운 시설을 칼로 부숩니다(시설 체력 120 + 업그레이드 단계마다 30). 공격받는 시설에는 체력 막대가 보입니다.
- 주인공이 회복하면 해적은 다시 주인공과 싸우고, 주인공이 끝까지 물리쳐야 습격이 끝납니다.
- 부서진 시설은 기울어지고 연기가 나며 생산·판매가 멈춥니다. 할 일이 없는 일꾼이 스스로 가서 고칩니다(시설 하나에 최대 3명, 일꾼 1명 기준 4초, 머리 위 🔧 표시). 주인공이 옆에 2초 서 있어도 수리됩니다. 근처에 해적이 있으면 수리되지 않습니다.
- 가판대에는 들고 있는 물건을 **개수 제한 없이 전부** 올릴 수 있습니다(화면에는 30개까지 쌓아 보여 줌).
- 일꾼은 일할 때 칼을 넣어 두고, 해적과 맞붙을 때만 칼을 손에 쥡니다.

## 안정성 보완 (레드팀 점검 반영)

- **진행 불가 방지:** 한 습격에서 선장이 3번 쓰러지고 다른 방어 인원도 없으면, 해적이 돈의 25%를 약탈하고 물러나 습격이 끝납니다(촉수는 가라앉음).
- **긴급 무료 충원:** 살아 있는 일꾼이 없고 돈이 $30 미만이면, 습격이 없을 때 텐트 충원 칸이 무료가 됩니다. 일꾼이 부서진 시설을 고치면 수입이 다시 생깁니다.
- **휴대폰 성능:** 캐릭터 갑옷·뼈 무늬 조각을 같은 색끼리 합쳐 그리기 부담을 줄였습니다(큰 습격에서 프레임 시간 약 34% 감소). 터치 화면에서는 갑판에 동시에 있는 해적을 최대 30명으로 제한합니다(총 상륙 인원 3배는 유지, 나눠서 상륙).
- **작은 화면:** 특수 습격 이름을 화면 위 따로 띄우지 않고 아래 방어 정보 줄에 함께 표시합니다.
- **선술집 이용 제한:** 하루 20판까지, 3번 연속으로 지면 1분 동안 쉬어 가기 안내가 나옵니다. 가상 돈이라도 잃은 걸 되찾으려고 계속 거는 흐름을 막기 위한 장치입니다.

## 시설 배치 정리

- 영웅·선원 훈련소는 위쪽 가운데(예전 빗물 정수기 자리)로, 빗물 정수기는 오른쪽 위(물 배급소 근처)로 자리를 바꿨습니다.
- 태양광 패널과 구조 신호탑은 없앴습니다. 예전 저장에서 지었거나 돈을 넣어 둔 경우 그 금액을 한 번 돌려받습니다. 뗏목 확장(2차)은 물 배급소를 지은 뒤 열립니다.

## 영웅·선원 강화 시설

첫 뗏목 확장과 일꾼 텐트 건설을 마치면 오른쪽 훈련 부두에 두 시설의 건설 칸이 나타납니다. 기존 저장으로 접속해도 부두가 연결됩니다.

| 시설 | 건설비 | 첫 강화 비용 | 단계마다 얻는 효과 |
|---|---:|---:|---|
| 영웅 훈련소 | $100 | $60 | 주인공 공격력 +3, 최대 체력 +10 |
| 선원 훈련소 | $120 | $50 | 모든 일꾼 공격력 +1, 최대 체력 +5 |

- 각 시설 앞 네모 칸(영웅 강화·일꾼 강화)에 주인공이 서 있으면 **건설·업그레이드 칸과 같은 방식으로** 돈이 조금씩 들어가 게이지가 차고, 다 차면 한 단계 강화됩니다. 칸에는 남은 금액이 표시되고, 칸을 떠나면 결제가 멈추며 넣어 둔 돈(게이지)은 저장되어 다음에 이어집니다. 별도의 강화 화면은 열리지 않습니다.
- 각각 최대 **50단계**입니다. 강화 비용은 현재 단계 기준 영웅 `$60 + 단계 × $25`, 선원 `$50 + 단계 × $20`으로 완만하게 증가합니다. 돈이 부족하거나 시설을 짓지 않았거나 영웅이 쓰러져 있으면 구매할 수 없습니다.
- 강화는 전투 레벨·카드와 함께 적용됩니다. 현재 일꾼과 나중에 $30로 충원한 일꾼 모두 선원 강화 효과를 받으며, 별도 해군 병사의 능력치는 유지합니다.
- 강화 시 기존에 잃은 체력은 유지하며 최대 체력 증가분만 채워 줍니다. 죽은 일꾼은 부활하지 않습니다. 시설·강화 단계·유닛 체력은 저장됩니다.

## 판매소 배정과 손님 구매

- 오른쪽 아래 **👷 일꾼 배정**에서 각 판매소의 담당 인원을 +/−로 지정합니다. 배정 합계는 살아 있는 인원이 아닌 텐트 전체 정원을 기준으로 제한합니다.
- 담당자는 지정 판매소에 상품을 공급하고 판매 대금을 수거합니다. 식당 담당자는 화로에 생선을 공급하는 작업도 맡습니다. 같은 작업자의 도착 지점을 분산하고 겹친 일꾼을 분리합니다.
- 전사해도 지정 정원은 유지됩니다. 텐트 앞에서 기존과 같이 $30·1초로 충원하면 결원을 채웁니다. 배정과 근무지는 저장됩니다. 새 판매소에는 배정 화면에서 인원을 지정하세요.
- 손님은 갑판 바깥의 구매 부두로 찾아와 줄을 섭니다. 카운터에 도착한 손님에게만 상품을 한 개씩 판매하고, 물건을 받은 손님은 부두 밖으로 돌아갑니다. 재고가 없으면 기다리다가 떠납니다. 판매 대금은 기존 수금 위치에 쌓이며 영웅과 담당 일꾼이 수금합니다. 새로고침 후에도 재고·매출은 보존하고, 방문객은 새로 생성해 중복 결제하지 않습니다.
- 배정을 바꾸는 도중 들고 있던 다른 상품은 원래 생산소로 반환해 잃지 않습니다. 운반물은 영웅·선원의 머리 위 중앙에 쌓으며 크기와 적재 간격은 기존의 3배입니다.

## 습격 간격

- 첫 확장 후 첫 습격과 각 전투 종료 뒤 다음 습격까지 **게임 시간 60초**를 준비합니다. 진행 중인 전투에 다음 습격을 겹쳐 생성하지 않습니다.
- 밀수 카드와 정찰로 간격을 줄이거나 늘리지 않습니다. 정찰은 받는 피해를 15% 낮춥니다.
- 이전 버전의 대기 중인 습격은 처음 접속할 때 한 번만 60초로 전환합니다. 이후 새로고침에서는 남은 시간이 유지됩니다.
- 이미 결제한 예전 5초 모집은 재결제 없이 남은 시간을 최대 1초로 줄여 이어받습니다.

## 공개 배포와 QR코드

게임은 **Cloudflare Pages**로 배포합니다. `main`에 올리면 Cloudflare가 자동으로 다시 배포합니다.

| Cloudflare Pages 설정 | 값 |
|---|---|
| Project name | `first-village-game` |
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `sh src/tools/build_site.sh` |
| Build output directory | `_site` |

`build_site.sh`는 로컬 엔진 파일의 SHA-256을 확인한 뒤 게임 실행 파일(`index.html`, `raft-village-3d.html`, `models`, `assets`, `vendor`)을 `_site`에 모읍니다. `vendor`에는 엔진 라이선스·출처·검증 목록도 포함됩니다. 애플리케이션 소스·테스트는 공개 폴더에 넣지 않습니다.

주소가 바뀌면 QR을 다시 생성합니다 (Python 패키지 `qrcode==8.2` 필요).

```bash
python3 src/tools/generate_qr.py --base-url https://first-village-game.pages.dev
```

Python Playwright, Pillow(렌더 캡처 확인), Chromium(`/usr/bin/chromium`), curl이 필요합니다. 저장소에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행한 뒤 별도 터미널에서 실행합니다.

```bash
python3 tests/update_game.py
python3 tests/worker_recovery_game.py
python3 tests/ui_reliability_game.py
python3 tests/storage_game.py
python3 tests/startup_game.py
python3 tests/customer_sales_game.py
python3 tests/customer_visual_game.py
python3 tests/mobile_viewport_game.py
python3 tests/mobile_hud_game.py

```

업데이트 검사는 `python3 tests/update_game.py --section progression`처럼 `logistics`, `progression`, `persistence`, `visual`, `mobile`을 독립 실행할 수 있습니다. 전체 실행에서는 한 섹션이 실패해도 다른 섹션을 검사한 뒤 실패 종료 코드를 반환합니다. 새 검사는 저장 오류·백업·레벨 50 경계·구버전 이관·파손 시설과 짐 보존·700~940px 화면·배정창 키보드 포커스·CDN 차단·WebGL 실패를 포함합니다.

준비 비용·효과, 중복 선택 방지, 저장·습격 복구, 방어 보상 중복 방지, 3D 카드 선택 복구와 JavaScript 실행 오류를 확인합니다. 테스트는 별도 브라우저 컨텍스트에서 실행되며 실제 사용자의 저장 데이터를 건드리지 않습니다. 화면 검증은 터치와 DPR 2를 설정한 모바일 브라우저 문맥에서 viewport 배율·HUD 겹침·터치 스크롤·드래그 방향을 확인합니다. 데스크톱 키보드 조작, 시설 표시, 습격 안내와 전투 카메라도 검사합니다. 외부 글꼴은 테스트에서 제외하며 three.js는 배포에 포함된 로컬 파일을 사용합니다. 실물 휴대폰의 성능 검사는 별도로 필요합니다.

Henry 모형을 바탕으로 남색 옷·갈색 머리로 색을 바꾸고, 금빛 조개 볏을 단 둥근 은빛 투구·가슴판·어깨 보호대·큰 은빛 주먹·장화·산호색 목도리를 뼈대에 붙여 원본 걷기·달리기·전투·사망 동작을 그대로 따라갑니다. 일꾼(선원)은 오리지널 "뼈다귀 곰 선원"입니다. 같은 Henry 동작 위에 몸보다 큰 둥근 곰 해골 머리(반짝이는 눈·분홍 볼터치·분홍 귀 안쪽·동그란 코), 머리와 같은 하얀 몸, 연한 라벤더색 뼈 무늬, 동그란 꼬리, 청록 선원 스카프를 입혔습니다. 손님은 참고 이미지의 파란 아기 돌고래를 바탕으로 만든 3D 캐릭터입니다. 커다란 머리와 반짝이는 눈, 하얀 배와 주둥이, 분홍 볼, 노란 불가사리 장식, 지느러미와 꼬리를 갖추고 걸어서 방문합니다.

  - 🌩 **폭풍 습격:** 해적 이동 +30%, 비와 어두운 하늘.
  - 🐙 **바다 괴물:** 뗏목 가장자리에 촉수 3개(일반 해적 체력의 3배)가 솟아 가까운 아군 주변을 내려칩니다. 촉수를 모두 베어야 습격이 끝납니다.
- **성장 균형:** 선장·선원의 단계별 성장은 6%(이전 10%), 해적은 레벨마다 3%입니다. 후반에 아군이 지나치게 강해지지 않게 조정했습니다.
- **🗺 섬 지도:** 원정 섬이 5곳으로 늘었습니다. 앞 섬을 처음 정복하면 다음 섬이 열리고, 준비 화면에서 열린 섬을 골라 다시 도전할 수 있습니다.

## 섬 원정 — 중반 항로 개척

화면의 🏝 버튼은 초반부터 다음 목표를 예고합니다. 첫 뗏목 확장·정수기 건설·해적 5회 방어를 달성하면 출항할 수 있습니다. 기존 항로 확보 보상 $200은 그대로 한 번 지급됩니다. 습격 중이거나 선장이 회복 중이면 출항하지 못합니다.

- 출항 준비에서 식량 꾸러미($20)와 물통($15)을 각각 1~3개 구매합니다. 식량은 탐험 체력, 물은 활동 시간을 늘립니다. 동행 선원은 보급비 $10/명으로 0~3명을 선택하며 마을에 최소 2명을 남깁니다. 동행 1명마다 구조·회수 범위가 넓어지고 공격 피해가 줄어듭니다.
- 동행자는 실제 마을 명부에서 빠집니다. 준비 화면과 탐험·귀환 결과 화면에서는 생산·손님 거래·수금·수리·모집·훈련·임금·습격 등 마을 시간이 함께 멈추고, 마을로 돌아가면 같은 시점부터 이어집니다. 화면 밖에서 마을이 공격받거나 임금이 밀리지 않습니다.
- 섬은 별도의 평면 탐험 화면입니다. 모바일은 화면을 드래그하고 PC는 방향키 또는 WASD로 이동합니다. 생존자 2명과 자원 상자 3개에 접근한 뒤 왼쪽 아래 배로 돌아오세요. 붉은 공격 범위가 나타나면 벗어나야 합니다. 체력 또는 활동 시간이 소진되면 실패하며 즉시 철수도 가능합니다.
- 실패·철수에도 동행자는 짐과 함께 모두 복귀하고 기존 마을은 유지됩니다. 소비한 물자 비용만 돌려받지 못합니다.
- 첫 성공은 **해초 보존식 제조법**을 해금합니다. 마을의 생선과 물을 하나씩 사용해 12초마다 보존식을 만들고(최대 20개), 생선 가판대·식당을 방문한 손님이 기존 상품과 함께 구매하면 판매소에 $18이 추가됩니다. 기존 일꾼이나 선장이 수금합니다.
- 두 번째 성공은 **의무병 배치**를 해금합니다. 원정 화면에서 첫 생존 일꾼을 의무병으로 전환하면 생산·운반·수금을 쉬는 대신 비전투 중 일꾼들을 초당 체력 1씩 추가 회복시킵니다. 생산 복귀로 전환할 수 있고 방어에는 계속 참여합니다.
- 세 번째 성공은 **탐험 나침반**을 해금해 선장 공격력을 20% 높입니다. 성공마다 $120을 받고, 세 가지 기능을 모두 해금한 이후에는 보존식 5개도 받습니다. 같은 섬에 다시 도전할 수 있습니다.

원정 선택·출항·탐험 위치와 공격 예고·구조 및 회수·귀환 결과를 기존 저장에 함께 보관합니다. 출항과 귀환은 저장 성공을 확인한 뒤 확정하며 저장 실패 시 비용·선원·보상을 되돌려 재시도할 수 있습니다. 탐험 중에는 진행 저장과 JSON 백업도 사용할 수 있습니다. 기존 저장의 재화·시설·능력치·선원은 유지됩니다.

## 해적 선술집 포커

첫 뗏목 확장 후 메뉴의 **해적 선술집 → 선술집 포커**에서 선택적으로 즐깁니다. 판돈은 마을에서 번 가상 돈 $10·$20·$30이며 현금 결제나 환전은 없습니다. 5장 중 유지할 카드를 누르고 **교환하고 승부**를 선택하면 나머지를 한 번 교환해 해적 딜러와 비교합니다. 딜러도 페어 이상을 보존하며 한 번 교환합니다. 승리 시 판돈의 2배를 받고, 무승부면 판돈을 돌려받으며 패배하면 판돈만 잃습니다. 별도 추가 베팅은 없습니다.

선술집을 보는 동안 마을 생산·습격·임금은 함께 정지합니다. 중간에 마을 메뉴로 나가도 받은 패·유지 선택·이미 낸 판돈은 저장되어 같은 판으로 복귀합니다. 새로고침으로 카드를 다시 받거나 이미 정산한 보상을 다시 받을 수 없습니다. 저장에 실패하면 판돈 차감·카드 교환·정산을 취소하고 재시도할 수 있습니다. 원정 진행 중에는 입장하지 못하고, 습격 중에는 새 판을 시작하지 못합니다. 중반 진행이나 원정 해금에 포커 승리는 필요하지 않습니다.

검사: `python3 tests/tavern_game.py` — 족보 9종·A와 키커, 입장/자금 제한, 카드 중복 없음, 새로고침, 승패/무승부 정산, 저장 실패 롤백, 모바일 화면과 키보드 포커스.

포커 저장 일부가 손상되면 정상 카드·덱의 누락된 유지 선택만 복구하고, 그 밖의 손상된 판은 따로 보관합니다. 마을 재화·시설·선원은 초기화하지 않습니다. 백업하거나 **손상된 포커판만 종료**할 수 있으며 추가 차감·임의 보상은 없습니다. 다른 탭에서 포커 기록이 바뀐 것을 발견하면 오래된 탭의 수동·자동 저장을 차단합니다. **최신 저장 불러오기**로 최신 판돈과 정산 결과를 이어가세요. 이 보호는 포커 기록 충돌을 다루며, 여러 탭의 마을 진행을 병합하는 기능은 아닙니다.
