# 표류 뗏목 마을

대홍수 이후 바다 위에 남은 뗏목에서 생존자들을 먹이고, 선원을 모아 정착지를 키우고, 쳐들어오는 해적을 막아내는 생존 경영 게임입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `raft-village-3d.html` | 3D 버전 (three.js). 동작이 들어간 캐릭터, 해골 해적, 보스, 강화 카드 포함 |
| `raft-village-2d.html` | 2D 버전 (Canvas). 3D 버전이 쓰는 기본 게임 규칙도 여기에 있음 |
| `models/*.json` | 3D 캐릭터 모형과 동작 (glTF). 3D 버전과 같은 폴더 구조로 두어야 함 |
| `src/3d/` | 3D 버전 소스. `w3d_*.js` 모듈과 조립 스크립트 `assemble3d.py` |
| `src/tools/` | Blender 변환 스크립트 (팩 .blend → glTF, Mixamo 걷기 동작 옮기기) |
| `assets/qr-3d.png`, `assets/qr-2d.png` | 온라인 플레이 링크 QR코드 |

2D 버전은 HTML 파일 하나로 동작합니다. 3D 버전은 `models` 폴더가 함께 있어야 캐릭터가 나오고, 없으면 도형 캐릭터로 대신 실행됩니다. 글꼴(Google Fonts)과 three.js는 인터넷에서 불러옵니다.

## 3D 버전 다시 만들기

`src/3d`의 모듈이나 `raft-village-2d.html`을 고친 뒤 저장소 맨 위에서 실행합니다.

```bash
python3 src/3d/assemble3d.py
```

2D 파일의 게임 규칙 위에 3D 모듈을 얹고, 3D 전용 규칙(30초 습격, 해적 레벨업, 강화 카드 등)을 덧입혀 `raft-village-3d.html`을 새로 만듭니다.

## 실행 방법

- **PC:** 2D는 HTML 파일을 브라우저로 열면 바로 실행됩니다. 3D는 캐릭터 파일을 불러와야 해서 간단한 웹 서버로 여는 것이 좋습니다 (예: 저장소 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000/raft-village-3d.html`).

## 조작

- 화면을 끌어서 이동 (PC: WASD / 방향키)
- 시설 옆에 서 있으면 물건을 자동으로 싣고 내림
- 왼쪽 아래 🎒 또는 Q 키로 가방 비우기
- 점선 칸 위에 서 있으면 돈이 들어가고, 다 채우면 건설·업그레이드

## 주요 기능

- **생산과 판매:** 낚시터, 숯불 화로, 빗물 정수기, 텃밭과 가게 4곳. 손님은 기다릴수록 표정이 바뀌고 15초가 지나면 떠남
- **선원:** 텐트마다 동물 모자를 쓴 선원 2명이 합류하고, 증축할 때마다 2명씩 추가. 할 일을 골고루 나눠 맡고 쌓인 돈도 주움. 신발·가방 장비 업그레이드
- **성장:** 레벨, 건물 ★5 업그레이드, 뗏목 확장, 물고기 떼, 업적형 미니 퀘스트
- **방어:** 망루 포탑과 포대, 총을 든 해군. 해적선과 상륙한 해적이 쳐들어오고, 해군은 해적마다 나뉘어 맞섬. 마을이 함락되면 자금 약탈·해군 이탈·시설 파손
- **저장:** 진행 상황은 브라우저에 자동 저장 (2D와 3D는 따로 저장)

### 3D 버전 전용

- **캐릭터:** 토끼 귀 모자를 쓴 주인공이 사람처럼 걷는 동작(Mixamo 걷기)으로 움직임. 선원·손님은 팩 캐릭터의 걷기·달리기·칼싸움·쓰러짐 동작 사용
- **해골 해적:** 해골 머리에 삼각 해적 모자를 쓴 해적과, 검은 해골 돛·빨간 깃발·대포를 단 둥근 해적선
- **습격:** 30초마다 습격. 습격할 때마다 해적이 레벨업하여 체력·공격력이 10%씩 복리로 상승
- **해적 종류:** 일반, 💣 폭탄(시설에 닿으면 폭발), 💰 도둑(돈을 훔쳐 배로 도망, 잡으면 되찾음), 🎯 저격(멀리서 선원을 쏨)
- **보스:** 5번째 습격마다 해골 선장의 거대 해적선. 일제 사격과 졸개 소환
- **강화 카드:** 습격을 막을 때마다 12종 중 3장이 나오고 1장을 골라 판마다 다르게 성장
- **화면:** 언제나 낮, 바닥은 한 가지 베이지색
