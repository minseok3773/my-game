# 표류 뗏목 마을

대홍수 이후 바다 위에 남은 뗏목에서 생존자들을 먹이고, 선원을 모아 정착지를 키우고, 쳐들어오는 해적을 막아내는 생존 경영 게임입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `raft-village-3d.html` | 3D 버전 (three.js). 실시간 그림자, 빛 번짐, 목책, 보호막 등 연출 포함 |
| `raft-village-2d.html` | 2D 버전 (Canvas). 같은 게임 규칙을 2D 아이소메트릭으로 표현 |
| `assets/qr-3d.png`, `assets/qr-2d.png` | 온라인 플레이 링크 QR코드 |

두 파일 모두 HTML 파일 하나로 동작합니다. 글꼴(Google Fonts)과 3D 버전의 three.js는 인터넷에서 불러옵니다.

## 실행 방법

- **PC:** HTML 파일을 브라우저(크롬, 엣지 등)로 열면 바로 실행됩니다.
- **휴대폰:** 아래 온라인 링크나 QR코드로 여세요.
  - 3D: https://claude.ai/artifact/BoAAuADnZZY2Tf1SYMdeg9
  - 2D: https://claude.ai/artifact/U1UfocAvdezpwGo3rWH2ek
- GitHub Pages를 켜면 `https://minseok3773.github.io/my-game/raft-village-3d.html` 주소로도 실행할 수 있습니다.

## 조작

- 화면을 끌어서 이동 (PC: WASD / 방향키)
- 시설 옆에 서 있으면 물건을 자동으로 싣고 내림
- 왼쪽 아래 🎒 또는 Q 키로 가방 비우기
- 점선 칸 위에 서 있으면 돈이 들어가고, 다 채우면 건설·업그레이드

## 주요 기능

- **생산과 판매:** 낚시터, 숯불 화로, 빗물 정수기, 텃밭과 가게 4곳. 손님은 기다릴수록 표정이 바뀌고 15초가 지나면 떠남
- **선원:** 텐트마다 동물 모자를 쓴 선원 2명이 합류하고, 증축할 때마다 2명씩 추가. 할 일을 골고루 나눠 맡고 쌓인 돈도 주움. 신발·가방 장비 업그레이드
- **성장:** 레벨, 건물 ★5 업그레이드, 뗏목 확장, 물고기 떼, 업적형 미니 퀘스트
- **방어:** 망루 포탑과 포대, 총을 든 해군. 해적선과 상륙한 해적이 쳐들어오고, 해군은 해적마다 나뉘어 맞섬. 마을이 함락되면 자금 약탈·해군 이탈·시설 파손
- **저장:** 진행 상황은 브라우저에 자동 저장 (2D와 3D는 따로 저장)
