# 표류 뗏목 마을 3D

대홍수 이후 바다 위에 남은 뗏목에서 생존자들을 먹이고, 선원을 모아 정착지를 키우고, 쳐들어오는 해골 해적을 막아내는 3D 생존 경영 게임입니다.

## 바로 하기

- 휴대폰·PC 브라우저: https://claude.ai/artifact/BoAAuADnZZY2Tf1SYMdeg9
- QR코드: `assets/qr-3d.png`

## 파일

| 파일 | 내용 |
|---|---|
| `raft-village-3d.html` | 게임 파일 (three.js). 조립 스크립트가 만든 결과물 |
| `models/*.json` | 캐릭터 모형과 동작 (glTF). 게임 파일과 같은 폴더 구조로 두어야 함 |
| `src/3d/base.html` | 게임 규칙과 화면 UI의 바탕 파일 |
| `src/3d/w3d_*.js` | 3D 모듈: 장면, 바다·뗏목·해적선, 캐릭터, 효과, 강화 카드·해적 종류·보스 |
| `src/3d/assemble3d.py` | 바탕 파일과 3D 모듈을 합쳐 게임 파일을 만드는 스크립트 |
| `src/tools/` | Blender 변환 스크립트 (팩 .blend → glTF, Mixamo 걷기 동작 옮기기) |
| `assets/qr-3d.png` | 온라인 플레이 링크 QR코드 |

## 게임 파일 다시 만들기

`src/3d`의 파일을 고친 뒤 저장소 맨 위에서 실행합니다.

```bash
python3 src/3d/assemble3d.py
```

`base.html`의 게임 규칙 위에 3D 모듈을 얹고, 3D 전용 규칙(30초 습격, 해적 레벨업, 강화 카드 등)을 덧입혀 `raft-village-3d.html`을 새로 만듭니다.

## PC에서 파일로 실행

캐릭터 파일(`models`)을 불러와야 해서 간단한 웹 서버로 여는 것이 좋습니다. 파일을 그냥 열면 도형 캐릭터로 대신 실행됩니다.

```bash
python3 -m http.server
```

그다음 브라우저에서 `http://localhost:8000/raft-village-3d.html`을 엽니다. 글꼴(Google Fonts)과 three.js는 인터넷에서 불러옵니다.

## 조작

- 화면을 끌어서 이동 (PC: WASD / 방향키)

## 주요 기능

- **생산과 판매:** 낚시터, 숯불 화로, 빗물 정수기, 텃밭과 가게 4곳. 손님은 기다릴수록 표정이 바뀌고 15초가 지나면 떠남
- **선원:** 텐트마다 선원이 합류해 일을 골고루 나눠 맡고 쌓인 돈도 주움. 습격 때는 해적과 싸우고, 쓰러지면 45초 뒤 텐트에서 새 선원이 옴
- **성장:** 레벨, 건물 ★ 업그레이드, 뗏목 확장, 물고기 떼, 업적형 미니 퀘스트
- **캐릭터:** 토끼 귀 모자를 쓴 주인공이 사람처럼 걷는 동작(Mixamo 걷기)으로 움직임. 선원·손님은 걷기·달리기·칼싸움·쓰러짐 동작 사용
- **해골 해적:** 해골 머리에 삼각 해적 모자를 쓴 해적과, 검은 해골 돛·빨간 깃발·대포를 단 둥근 해적선
- **습격:** 30초마다 습격. 습격할 때마다 해적이 레벨업하여 체력·공격력이 10%씩 복리로 상승
- **해적 종류:** 일반, 💣 폭탄(시설에 닿으면 폭발), 💰 도둑(돈을 훔쳐 배로 도망, 잡으면 되찾음), 🎯 저격(멀리서 선원을 쏨)
- **보스:** 5번째 습격마다 해골 선장의 거대 해적선. 일제 사격과 졸개 소환
- **강화 카드:** 습격을 막을 때마다 12종 중 3장이 나오고 1장을 골라 판마다 다르게 성장
- **방어:** 망루 포탑과 포대. 마을이 함락되면 자금 약탈·시설 파손
- **화면:** 언제나 낮, 바닥은 한 가지 베이지색
- **저장:** 진행 상황은 브라우저에 자동 저장
